# Sri Chamundi Tours and Travels (Tours and Travels web 1)

Static website template for a travel agency in Jayanagar, Bengaluru. No build step.

## Preview
Open `public/index.html` in a browser, or run `npx serve public`.

## Deploy on Vercel
Framework preset: Other. Root directory: this folder. Output directory: `public`. No build command.
